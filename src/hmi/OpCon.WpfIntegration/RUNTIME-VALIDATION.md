## 样例边界与前置条件

使用独立自有 `IntegrationProbe` 对象/消费者，无机器人或物理 I/O。标准 OpCon Unit 提供参数 Setpoint、离散 Pulse 和适用的按住型 Hold；HMI 使用当前 CoDeSysV3/PLCHandler 通路。不能用宿主直接写请求位代替原生控制。

先与实际唯一所有者确认：精确工程/PID/profile/session、当前登录与离线状态、没有结果未知的操作、已有可恢复起点、谁负责切换和恢复。需在线虚拟运行时另确认虚拟目标身份，不能把当前已登录的工程当作可借用窗口。现有 ST40 模型添加副本的 Export/编译任务仍保留，按同一所有权依赖安排。

## PLC 测量契约

PLC 每个扫描周期独立更新 ScanCount，记录 TaskCycle/LastCycle/MaxCycle 和 Unit 状态。参数提交、离散命令和按住型请求分别记录接收次数、接收序号、起止扫描号、结果及错误。自动进展另有 AutoCount；不等待 HMI 消息或 UI 确认。

从实际配置记录任务周期和允许周期/调用耗时，测试前后均采集原始值。按住型的失效期限及响应来自本虚拟探针明确的控制器契约，并测量 PLC 侧最后一次有效请求至释放的扫描差；不能套用宿主默认 2000 ms 或写成通用机器人停止时间。

## 需要取得的实际证据

| 用例 | 检查点 |
| --- | --- |
| 参数输入/提交/取消 | 原生权限、令牌、Condition、限值成立才提交；PLC 回读等于确认值；取消不增加提交数 |
| 无权限/无令牌/无放行 | 分别拒绝，PLC 请求次数不增加；不得为测试临时屏蔽原生保护 |
| 离散 Pulse | 真实按下/释放后仅一次接收，Running→完成/错误与序号相符；重复输入按原生 Busy 语义处理 |
| 按住 Hold | 按住有真实请求/反馈，松开有控制器接收的释放；分别核验鼠标、触摸和适用键盘操作 |
| 松开丢失/焦点/捕获丢失 | 控制器在既定期限内释放或转入声明状态；记录扫描差与 Unit 状态 |
| 换页/编辑中换页 | 原生释放/取消规则生效，未确认参数不写入；重新进入先未知再读新鲜状态 |
| HMI 暂停、无响应及退出 | ScanCount/AutoCount 持续推进，周期在既定限值内；按住请求失效；不能只检查 HMI 定时器 |
| 断线、重连、重开 | 坏质量转未知，恢复零控制重放；待新心跳后读取当前 Running/结果，不自动接管未知动作 |
| 命令执行中故障 | 结果明确或保持未知；恢复不重复接收同一命令，不用“静止/启动成功”代替完成 |
| 多实例 | 参数、反馈、计数与按键各归本 Unit，前缀变化不复用旧实例；互不抢占同一控件 |
| 原生中英文 | 改语言本身零提交/零请求，编辑值与原生执行状态保留；英文长度及触摸键盘可用 |
| DPI/焦点 | 100/125/150/200% 实际 HMI，普通/最大窗口、Tab/Space/Enter/Esc、触摸/鼠标和换页不裁切、不点错 |
| 资源释放 | 反复打开/关闭后自有 Item、事件、窗口和控件占用回到基线；不留下捕获和订阅 |
| 正常生成/部署 | Parse/Save/Export、原生编译，两次 Export 与冷重开保留 DLL、布局、文本、GUI 引用和控件契约 |
